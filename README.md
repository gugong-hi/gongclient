# gongclient

## 크레딧

- [TClient](https://github.com/TaterClient/TClient) — Gong Client의 기반 프로젝트. TClient 제작진과 기여자에게 감사드립니다.
- [DDNet](https://github.com/ddnet/ddnet) — TClient가 기반으로 하는 프로젝트.
- [BestClient](https://github.com/BestProjectTeam/BestClient) — Cloud 입력 방식 설계를 참고한 프로젝트. BestClient 제작진과 기여자에게 감사드립니다.

Gong Client는 TClient를 수정한 프로젝트입니다. 원본 저작권 및 라이선스 표기는 `license.txt`와 각 파일에 유지합니다.
